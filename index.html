نصائح الاستخدام

مفتاح Gemini API — أضف مفتاحك الخاص لتجنب القيود ورفع جودة الترجمة والتحليل.

مونتاج سندوتش — الأفضل للكونتنت الاحترافي مع B-Roll وتأثيرات متعددة الطبقات.

SRT Splitter — استخدمها قبل المونتاج لتقسيم الترجمة الطويلة لمقاطع مناسبة.

محلل الفيديو — حلّل فيديو مرجعي لاستخراج قواعد مونتاجه وتطبيقها تلقائياً.

تصدير XML — صدّر مشروعك كـ FCPX XML للتوافق مع محررات احترافية.
